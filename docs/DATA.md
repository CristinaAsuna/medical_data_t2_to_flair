# 数据：来源、契约和划分

永久文档，上限 150 行。数据契约只在这里定义，其他文件引用本文件，不重复写。

## 数据集

数据不随仓库分发。数据集放在各机器的 `$LAB_DATA_DIR/<标识>/`（各机器的值和资产登记见总台 MACHINES.md）。这里和代码里只写这个变量，不写某台机器的绝对路径。

| 标识 | 内容和规模 | 用途 | 不能混淆的边界 |
|---|---|---|---|
| `brats2021` | BraTS 2021 Task 1 训练集，1251 例胶质瘤；T1/T1ce/T2/FLAIR 已配准到 SRI24、去颅骨、1 mm，240×240×155；标注含坏死核心(1)/水肿(2)/增强肿瘤(4)。来源为 Kaggle 镜像（数据集 ID 下载时核实，记进 MACHINES.md） | 训练 / 验证 / 测试（按受试者划分） | 官方 validation 集没有公开标注，不使用；只用 T2、FLAIR 和标注，T1/T1ce 不进入模型 |
| `brats2021/processed` | 预处理后的 `.npy` 切片与掩膜，由 `t2flair.prep` 生成 | 同上 | 只能由本项目的预处理入口生成，不手工改 |

使用条款：⚠ 下载前核对 Kaggle 镜像和 BraTS 2021 的数据使用条款；论文按要求引用 BraTS 2021（Baid et al., arXiv 2107.02314）及其相关文献。

## 契约

- 文件名：`BraTS2021_<5位编号>/BraTS2021_<编号>_{t2,flair,seg}.nii.gz`；受试者 ID 即 `BraTS2021_<编号>`。
- 方向：用 nibabel 读入后保持原始体素顺序，轴向为最后一维（z）；不做重采样。
- 归一化：每个体积、每个模态单独处理；按脑区（该模态 >0）的 99.5 百分位截断，再线性映射到 [-1, 1]；脑外背景恒为 -1。不按切片归一化。
- 脑区 mask：T2 > 0 或 FLAIR > 0；所有画质指标只在这个 mask 内计算。
- 肿瘤掩膜 M（whole tumor）：标签 > 0。只在训练（病灶感知损失、分割器）和评测时使用，推理时不使用。
- 切片：保留脑区占比 > 10% 的轴向切片；中心裁剪到 192×192（240→192，各边裁掉 24 像素）。
- 模型输入：条件为第 z−1、z、z+1 张 T2（3 通道，体积边缘处复制最近的切片）；桥的起点为第 z 张 T2；目标为第 z 张 FLAIR。
- 数据增广：只用随机水平翻转，T2、FLAIR、M 同步翻转。

## 划分

- 单位：受试者（同一受试者的所有切片只出现在一个集合里）。
- **主协议**：用固定种子 0 从 1251 例中无放回地抽出 430 例，分为 train 300 / val 30 / test 100。ID 列表写进 `configs/splits/main_{train,val,test}.txt` 并提交；生成命令见 PIPELINE.md §1。
- **文献协议**（只用于说明与已发表数字的协议差异）：沿用 D3Bridge 公开脚本的做法，按 ID 排序后用种子 42 打乱，取 25 / 5 / 10 例，每例取轴向切片 [27, 127)。列表写进 `configs/splits/lit_{train,val,test}.txt`。
- **冻结的测试集**：`main_test`（100 例）不用于调参、早停、选 checkpoint 或选 σ/α/λ，只在最终报告时评测一次；开发阶段一律用 `main_val`。
- 分割器 S_train 和 S_eval 只用 `main_train` 训练，与生成模型共用训练集，不碰 val/test。

## 预处理

1. 读取 T2、FLAIR、seg 三个 NIfTI 文件，校验三者形状一致。
2. 计算脑区 mask，按上面的契约归一化。
3. 筛选切片、中心裁剪，保存为每个受试者一个 `.npz`（t2、flair、brain_mask、tumor_mask、slice_index）。
4. 输出写到 `$LAB_DATA_DIR/brats2021/processed/<协议>/`，并生成清单 `manifest.json`（受试者数、切片数、sha256）。
入口：`python -m t2flair.prep`（见 PIPELINE.md §1）。在集群上以 `bme_cpu` 作业运行。
